# Color

**Color** controls the hair color along the strand.

- Color is authored per strand with a ramp, so roots, mid-length and tips can differ.
- Color is one of the attribute groups you can copy between Ahoge shapes with **Paste Attributes → Color** (see [Misc tools](/documentation/misc)).
- Color is exported with the hair, including when you export to [Alembic](/documentation/alembic) for [Unreal Engine](/documentation/unreal).

## Tips

- Use subtle root-to-tip variation to give the hair more depth.
- Combine color variation with [Randomize Noise](/documentation/noise#randomize-noise) and [Multistrand](/documentation/multistrand) to break up large uniform areas.
- For render-side color work (shader networks, transmission, cutout opacity) see [Arnold](/documentation/arnold).

The full Color rollout, with attribute names, defaults and what each one does, is on the [ahogeShape attributes](/documentation/nodes/ahoge-shape#color) page.
